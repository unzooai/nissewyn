Why

Chat windows are not a workplace.

Inside their own apps, agents get a sandbox that forgets, a browser without your accounts, and either no limits or a question at every step. Nissewyn is not another chat app. It is the computer they work on.

A terminal that stays

Terminals live in a background service. Close the app and builds, servers and downloads keep running. Jump between command blocks, spot failed commands, hand a failure to an agent in one click, and run full-screen TUI tools without glitching.

A real browser, real sign-ins

A full Chromium with your accounts, and a separate identity for each agent. It downloads media and copes with captchas. When a login or a code is needed, it hands the page to you and waits.

Built on Unzoo Browser.

Rules you set

Every action is rated for risk. Reading and preparing just run. Sending, paying, deleting and installing wait for you — in the conversation, in your inbox, or on your phone. Everything is recorded.

How it works

Say what you want. Watch it get done.

No forms, no workflow builder. A conversation is a task.

Ask in plain words

“Every weekday at 9, check these competitor pages and tell me what changed.”

It works beside you

The agent's terminal and browser appear next to the conversation, live. Take over at any point.

Risky steps wait

You answer right where you are. Follow up in the same thread; the agent remembers.

It keeps going

On a schedule, or when a page, a folder, your mail or your calendar changes.

Safety

It asks about the one click that matters.

Asking at every step trains you to click “Allow” without reading. Nissewyn looks at what an action will actually do, and asks only when it leaves your computer, costs money or can't be undone.

Read, search, browseOpen pages, read files, run read-only commandsJust runs
PrepareType into a form, write a draft, edit files in the task folderJust runs
Send, publish, submitThe “Send” button, Enter in a message box, posting, uploading, pushingChecked
Pay, buy, installCheckout, place order, installing programs on the computerAsks you
DeleteRemoving files, clearing data, force-pushingAsks you

Checked against your words

Before asking, a reviewer — your own agent, with no tools — checks the send against what you asked for. If you clearly asked for it, it goes; otherwise you see the question and the reason.

Pages are data, not orders

A web page or an email that says “the user already agreed” counts for nothing. Only what you typed, or the task you saved, authorizes anything.

Sent once

The same send on the same page with the same text is never repeated silently. If it comes up again, you are asked — it may already have gone out.

FAQ

Common questions.

Do I need to install Claude Code or Codex first?

No. Starting in v0.1.7, Nissewyn includes a built-in API Model (BYOK) agent. Just pick a preset (DeepSeek, Qwen, Kimi, GLM, OpenAI, Anthropic, or local Ollama) and paste your API key — or use any of the 6 supported local CLIs whenever you want.

Do I need Unzoo Browser installed?

Only if you want agents to browse the web with your sign-ins. Terminal tasks, local file work, and non-browser plugins work immediately without it. When you install Unzoo Browser, Nissewyn detects it automatically on both macOS and Windows.

Where are my API keys, conversations, and files stored?

100% locally on your own computer. API keys are saved in a restricted local file (0600 on macOS/Linux) or system credential store and are never sent to our servers.

What happens if my computer sleeps or shuts down?

Nothing runs while your computer is off. Scheduled runs missed while it slept catch up automatically once it wakes up.

Can I build my own local plugin?

Yes — any folder with an unzoo-plugin.json works in any language (Python, Node.js, Go, Rust). See our Plugin Guide for the 5-minute template.

What does source-available (BSL 1.1) mean?

You can read, modify, build, and use Nissewyn for personal or internal company production use for free. You just cannot resell it as a hosted/managed competing service. After 4 years each release converts to Apache 2.0.
