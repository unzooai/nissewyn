v0.1.7

Latest · macOS Signed DMG
  • Built-in API Model (BYOK) agent: Run tasks with OpenAI-compatible and Anthropic-compatible APIs directly inside Nissewyn — no external CLI required. Includes 12 one-click presets (DeepSeek, Qwen, Kimi, GLM, MiniMax, Doubao/Ark, SiliconFlow, OpenAI, Anthropic, OpenRouter, local Ollama, Custom) with connection testing, full MCP tool calling, and approval governance.
  • Chinese CLI agents via ACP: Added native hosted support for Qwen Code CLI (qwen --acp) and Kimi Code CLI (kimi acp) alongside Claude Code, Codex, Antigravity CLI, and OpenCode.
  • macOS Unzoo Browser detection & onboarding: Auto-detects /Applications/Unzoo Browser.app and ~/Applications/, supports setup-mcp.sh, and provides direct download guidance when Unzoo Browser is not installed.
  • Plugin Guide & Developer Docs: Published docs/plugin-development.md and bilingual /plugins/ pages on nissewyn.com.

v0.1.6

macOS & Terminal
  • First Developer ID signed macOS (Apple Silicon) .app and .dmg bundle with sidecar nissewyn-service and nissewyn-cli.
  • Terminal command blocks: recognize each command, jump up/down, highlight failed commands, and hand failures to an agent in one click.
  • Xtools v2.4 human-like browsing (clicks links naturally instead of reloading whole pages) and polished plugin list refresh UX.
  • Ctrl+C console-helper fix so background services stay alive on interrupt.

v0.1.5 – v0.1.3

Runtime & Plugins
  • Synced unterm runtime to v0.72.0 and added high-throughput terminal output batching (~3x lower UI CPU).
  • App-wide network proxy settings for terminals, agents, plugins, and child tools.
  • Plugin manifest i18n (EN / 中文) and Xtools human schedule pacing.
  • Configurable terminal starting folder and raw byte replay for full-screen TUI apps.
