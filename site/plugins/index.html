Plugin Guide · Developer Docs

Build & run local plugins in Nissewyn.

A skill teaches an agent how to do a task. A plugin is a local program with its own control page, persistent state, settings form, and MCP tools — governed by the same approval rules.

5-minute quickstart Notes template on GitHub
Using plugins

Add any local plugin folder in seconds.

Open Plugins

Go to Plugins in Nissewyn and click Add plugin in the left sidebar.

Paste folder path

Point to any folder containing unzoo-plugin.json (e.g. plugins/xtools or examples/plugins/notes).

Bind roles & settings

Assign an Unzoo Browser identity and/or AI agent + model in the Settings tab.

Turn it on

Flip the switch in the header. Nissewyn launches the daemon, mounts its page, and exposes its MCP tools.

Quickstart

One manifest, any language.

Python, Node.js, Go, Rust — anything that serves HTTP on UNZOO_PLUGIN_PORT and/or speaks MCP JSON-RPC over stdio works out of the box.

Folder layout

my-plugin/
├── unzoo-plugin.json   # Manifest (required)
├── server.py           # Control page + /api/ping
├── mcp_server.py       # Stdio MCP tools (optional)
└── i18n/en.json        # Translations (optional)

Runtime environment variables

  • UNZOO_PLUGIN_ID — plugin identifier
  • UNZOO_PLUGIN_DIR — plugin folder path
  • UNZOO_PLUGIN_DATA — persistent data folder
  • UNZOO_PLUGIN_PORT — localhost HTTP port
  • UNZOO_PLUGIN_ROLES — JSON role bindings
  • UNZOO_PLUGIN_SETTINGS — JSON settings map

Minimal unzoo-plugin.json

{
  "id": "notes",
  "name": "Notes",
  "version": "0.1.0",
  "description": "Local notes page and MCP tools.",
  "run": {
    "command": ["python3", "{dir}/server.py"],
    "health": "/api/ping"
  },
  "page": "/",
  "mcp": {
    "command": ["python3", "{dir}/mcp_server.py"],
    "tools": {
      "list_notes": "read",
      "add_note": "change"
    }
  },
  "roles": {
    "account": { "kind": "browser", "label": "Browser identity" },
    "writer": { "kind": "agent", "label": "Writer" }
  }
}
Capabilities

Declarative settings, risk tags, and i18n built in.

Auto-generated settings

Declare settings in the manifest with types bool, number, text, textarea, choice, list, or range. Nissewyn renders the form, validates values, and restarts the plugin on save.

MCP risk governance

Tag each MCP tool in mcp.tools with read, change, run, send, pay, or delete. Undeclared tools default to send and ask for user approval.

Bilingual UI (i18n)

Point i18n to a JSON translation map for manifest labels. Nissewyn also opens your control page with ?lang=en or ?lang=zh-CN.

Build with AI

Let your agent write a plugin for you.

Paste this prompt into Claude Code, Codex, Antigravity CLI, or OpenCode inside Nissewyn:

Read docs/plugin-development.md and examples/plugins/notes/.
Build a new Nissewyn plugin in ~/my-plugins/rss-digest with:
- unzoo-plugin.json (settings + MCP tools tagged read/change)
- a local control page on UNZOO_PLUGIN_PORT storing state in UNZOO_PLUGIN_DATA
- a stdio MCP server exposing list_feeds and add_feed.
