插件指南 · 开发者文档

在 Nissewyn 里使用与开发本地插件。

技能（Skill）教智能体怎么做一件事；插件（Plugin）是运行在 Nissewyn 旁边的本地程序，拥有独立的控制页面、持久化数据、可视化设置表单和受安全规矩约束的 MCP 工具。

5 分钟快速上手 查看 Notes 模板
使用插件

四步接入任意本地插件。

打开插件页

进入 Nissewyn 侧栏的 插件 页面，点击左下角 添加插件。

填入文件夹路径

粘贴包含 unzoo-plugin.json 的目录路径（如 plugins/xtools 或 examples/plugins/notes）。

绑定角色与设置

在 设置 页为插件指定 Unzoo 浏览器身份和写稿/执行智能体与模型。

打开开关启动

开启右上角开关，Nissewyn 自动拉起后台进程、加载控制页面并挂载 MCP 工具。

快速开发

一份清单文件，语言不限。

Python、Node.js、Go、Rust 都可以——只要在 UNZOO_PLUGIN_PORT 提供 HTTP 页面，并通过 stdio 实现 MCP JSON-RPC 即可。

目录结构

my-plugin/
├── unzoo-plugin.json   # 插件清单（必需）
├── server.py           # 控制页面 + /api/ping
├── mcp_server.py       # stdio MCP 工具（可选）
└── i18n/en.json        # 多语言翻译（可选）

运行时注入的环境变量

  • UNZOO_PLUGIN_ID — 插件 ID
  • UNZOO_PLUGIN_DIR — 插件目录绝对路径
  • UNZOO_PLUGIN_DATA — 独立持久化数据目录
  • UNZOO_PLUGIN_PORT — 分配的本机 HTTP 端口
  • UNZOO_PLUGIN_ROLES — JSON 格式的角色绑定
  • UNZOO_PLUGIN_SETTINGS — JSON 格式的设置项

最简 unzoo-plugin.json

{
  "id": "notes",
  "name": "Notes",
  "version": "0.1.0",
  "description": "本地笔记控制页与 MCP 工具示例。",
  "run": {
    "command": ["python3", "{dir}/server.py"],
    "health": "/api/ping"
  },
  "page": "/",
  "mcp": {
    "command": ["python3", "{dir}/mcp_server.py"],
    "tools": {
      "list_notes": "read",
      "add_note": "change"
    }
  },
  "roles": {
    "account": { "kind": "browser", "label": "浏览器身份" },
    "writer": { "kind": "agent", "label": "写稿智能体" }
  }
}
核心能力

设置表单、风险治理与多语言开箱即用。

声明式设置表单

在清单 settings 里声明 bool、number、text、textarea、choice、list、range 字段，Nissewyn 自动渲染界面、校验范围，保存后自动重启插件读取新配置。

MCP 风险分级

在 mcp.tools 中为每个工具标注 read、change、run、send、pay 或 delete；未标注的工具默认按 send 处理，执行前先问你。

多语言界面（i18n）

通过 i18n 指定翻译 JSON 即可自动切换清单文案；控制页面打开时也会带上 ?lang=zh-CN 或 ?lang=en 参数。

让 AI 帮你写插件

直接交给智能体生成专属插件。

在 Nissewyn 里把下面这段话发给 Claude Code、Codex、Antigravity CLI 或 OpenCode：

请阅读 docs/plugin-development.md 和 examples/plugins/notes/，
在 ~/my-plugins/rss-digest 创建一个新的 Nissewyn 插件：
- 写好 unzoo-plugin.json（含设置项与按 read/change 标注的 MCP 工具）
- 用 UNZOO_PLUGIN_PORT 启动控制页面，数据存到 UNZOO_PLUGIN_DATA
- 提供 stdio MCP 服务，暴露 list_feeds 和 add_feed 两个工具。
