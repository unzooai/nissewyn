v0.1.7

最新版 · macOS 签名 DMG
  • 内置 API Model (BYOK) 智能体：无需安装外部 CLI，原生支持 OpenAI 兼容与 Anthropic 兼容协议。内置 12 组一键预设（DeepSeek、通义千问 Qwen、Kimi、智谱 GLM、MiniMax、豆包 / 火山方舟、硅基流动、OpenAI、Anthropic、OpenRouter、本机 Ollama、自定义），支持连通性测试、完整 MCP 工具调用与审批治理。
  • 原生支持国产 CLI（ACP 托管）：新增 Qwen Code CLI（qwen --acp）与 Kimi Code CLI（kimi acp），与 Claude Code、Codex、Antigravity CLI、OpenCode 并列可选。
  • macOS Unzoo 浏览器探测与引导：自动识别 /Applications/Unzoo Browser.app 与 ~/Applications/，兼容 setup-mcp.sh，未安装时提供一键下载引导。
  • 插件使用与开发指南：新增 docs/plugin-development.md 与官网中英文 /plugins/ 文档页。

v0.1.6

macOS 与终端升级
  • 首个 Developer ID 签名的 macOS（Apple Silicon）.app 与 .dmg 安装包，内置 nissewyn-service 与 nissewyn-cli。
  • 终端命令块：自动识别每条命令、上下跳转、高亮失败命令并一键交给智能体排查。
  • Xtools v2.4 拟人化浏览（进站后点链接走动，不再反复刷新整页）与插件列表刷新按钮体验优化。
  • 修复终端按 Ctrl+C 导致后台服务丢失控制台的问题。

v0.1.5 – v0.1.3

内核与插件生态
  • unterm 内核同步至 v0.72.0，终端高频刷屏合并读取使页面 CPU 降至约三分之一。
  • 新增全局网络代理设置，统一覆盖终端、智能体与插件子进程。
  • 插件清单支持中英双语（i18n），Xtools 支持按人的作息随机浏览与发帖。
  • 支持自定义终端启动文件夹，以及全屏终端程序按字节原样回放。
