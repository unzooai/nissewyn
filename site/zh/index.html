为什么

聊天窗口不是干活的地方。

在自家应用里，智能体拿到的是会忘事的沙盒、没有你账号的浏览器，要么什么都不管，要么每一步都问你。Nissewyn 不是又一个聊天应用，它是智能体干活用的电脑。

不会断的终端

终端住在后台服务里，关了应用照样跑。自动识别每条命令块、上下跳转、标出失败命令并一键交给智能体排查，完整支持全屏终端程序与高频刷屏流控。

真浏览器，真登录

完整的 Chromium，带你的账号，每个智能体一个隔离身份。能下载视频、处理验证码。要登录、要验证码时，把页面交给你，等你弄好。

基于 Unzoo 浏览器。

你定的规矩

每个动作按风险分级。看、准备，直接做；发送、付款、删除、装软件，等你点头——在对话里、收件箱里或手机上都行。全部留记录。

你睡觉时

Nissewyn 的一个晚上。

睡前交代一句。醒来时活已经干完，只剩一件该你拿主意的事。

电脑要开着——关机时什么都不会跑。睡眠时错过的任务，醒来后补跑。

  1. 23:10
    你交代一句，去睡觉“今晚盯着这三个价格页，把照片文件夹备份一下，有变化告诉团队。”
  2. 23:12
    它开始干活用它自己的浏览器身份打开页面，在它自己的终端里开始备份。
  3. 01:40
    有个页面变了前后都存下来，记下变了什么：一个套餐从 29 美元涨到 35 美元。
  4. 03:05
    备份做完12 GB 拷完、校验、记录。终端还在，想看随时看。
  5. 03:06
    有风险的那一步等你给团队发邮件会发到电脑外面，所以它写好草稿就停下，不会把你叫醒。
  6. 07:45
    早上的汇报三行简报，加一封等你说“发”的草稿。在手机上点一下也行。
怎么用

说一句你要什么，看着它做完。

不用填表，不用拖流程图。一段对话就是一个任务。

用大白话说

“每个工作日早上 9 点看一下这几个竞品网站，有变化告诉我。”

它在旁边干活

智能体用的终端和浏览器实时显示在对话旁边，你随时能接手。

有风险的等你

就地回答。接着在同一段对话里说，它记得前面的事。

它自己接着跑

按时间跑，或者网页、文件夹、邮件、日历有变化时跑。

内置技能库

自带 10+ 开放 Agent Skills 格式技能：终端、浏览器、交付物整理、内容多平台分发、短视频流水线、简报汇总。一件事跑通后可直接存为新技能。

一个中枢，多个帮手

主智能体可以把一段活交给另一个，比如 Claude Code 交给 Codex。长期帮手负责一块，记得自己做过什么。

手机上也能管

同一个 Wi-Fi 或 Tailscale 下：看对话、批准、接手、发任务。不走云端中转。

为智能体打磨的终端

支持默认启动文件夹、命令块跳转与失败高亮、一键交给智能体修错、刷屏合并节流，以及全局网络代理设置。

别的 AI 应用也能用

终端和浏览器通过 MCP 提供给 Claude 桌面版、Cursor 等，照样按同一套规矩管。

中文、英文

应用界面、插件控制页、手机页面和智能体问你的话，都跟着你的语言自动切换。

插件生态

安全

只在真正要紧的那一下问你。

每一步都问，人很快就会不看内容直接点“允许”。Nissewyn 看的是这个动作实际会造成什么：只有发到电脑外面、要花钱、或者撤不回来的时候才问你。

看、搜、浏览打开网页、读文件、运行只读命令直接做
准备往表单里填字、写草稿、改任务文件夹里的文件直接做
发送、发布、提交点“发送”、在消息框里按回车、发帖、上传、推送代码先核对
付款、购买、装软件结账、下单、在电脑上安装程序问你
删除删文件、清空数据、强制推送问你

对照你说过的话

问你之前，先由审核员——你自己的智能体，不带任何工具——核对这次发送是不是你要求的。你明确说过的就放行，否则把问题和理由一起摆给你。

网页内容只是材料

网页或邮件里写着“用户已经同意”一概不算。只有你输入的话、你保存的任务才算授权。

只发一次

同一页面、同一按钮、同样的内容，不会悄悄再发一遍。再次出现时一定问你，并提醒你可能已经发出去了。

隐私

一切都在你自己的电脑上。

任务、对话、邮箱密码、日历地址、浏览器登录状态，都不经过我们的服务器——个人版根本没有服务器。密码放在系统的凭据库里，从不交给智能体。

用你自己的智能体

思考交给你已经订阅的 Claude Code、Codex、Antigravity CLI、OpenCode。模型不用再买一份，也不绑死在一家厂商上。

说实话的取舍

电脑关着的时候不会跑。睡眠或关机时错过的任务，开机后补跑。7×24 在服务器上跑，放在规划中的企业版里。
