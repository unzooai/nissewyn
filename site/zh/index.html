小尼，住在你电脑里的 AI 小帮手。

你睡觉时它干活，数据不出门。智能体已经够聪明了，缺的是一个干活的地方。小尼（Nissewyn）给它们一个不会断的终端、一个带你登录状态的真浏览器、可扩展的本地插件，以及你定的规矩——都在你自己的电脑上。

支持 Claude Code、Codex、通义千问 Qwen Code、Kimi Code、Antigravity CLI、OpenCode，以及免装 CLI 的 API 模型（DeepSeek / Qwen / Kimi / GLM / 豆包 / Ollama 等）。

为什么

聊天窗口不是干活的地方。

在自家应用里，智能体拿到的是会忘事的沙盒、没有你账号的浏览器，要么什么都不管，要么每一步都问你。Nissewyn 不是又一个聊天应用，它是智能体干活用的电脑。

不会断的终端

终端住在后台服务里，关了应用照样跑。自动识别每条命令块、上下跳转、标出失败命令并一键交给智能体排查，完整支持全屏终端程序与高频刷屏流控。

真浏览器，真登录

完整的 Chromium，带你的账号，每个智能体一个隔离身份。能下载视频、处理验证码。要登录、要验证码时，把页面交给你，等你弄好。

基于 Unzoo 浏览器。

你定的规矩

每个动作按风险分级。看、准备，直接做；发送、付款、删除、装软件，等你点头——在对话里、收件箱里或手机上都行。全部留记录。

安全

只在真正要紧的那一下问你。

每一步都问，人很快就会不看内容直接点“允许”。Nissewyn 看的是这个动作实际会造成什么：只有发到电脑外面、要花钱、或者撤不回来的时候才问你。

看、搜、浏览打开网页、读文件、运行只读命令直接做
准备往表单里填字、写草稿、改任务文件夹里的文件直接做
发送、发布、提交点“发送”、在消息框里按回车、发帖、上传、推送代码先核对
付款、购买、装软件结账、下单、在电脑上安装程序问你
删除删文件、清空数据、强制推送问你

对照你说过的话

问你之前，先由审核员——你自己的智能体，不带任何工具——核对这次发送是不是你要求的。你明确说过的就放行，否则把问题和理由一起摆给你。

网页内容只是材料

网页或邮件里写着“用户已经同意”一概不算。只有你输入的话、你保存的任务才算授权。

只发一次

同一页面、同一按钮、同样的内容，不会悄悄再发一遍。再次出现时一定问你，并提醒你可能已经发出去了。

常见问题

你可能关心的问题。

必须先安装 Claude Code 或 Codex 才能用吗？

不需要。从 v0.1.7 开始，Nissewyn 内置了 API Model (BYOK) 智能体，直接在设置里选 DeepSeek、通义千问、Kimi、智谱 GLM、豆包、OpenAI、Anthropic 或本机 Ollama 填入 Key 即可使用；同时也原生支持 6 大本地 CLI。

没有安装 Unzoo 浏览器能运行吗？

可以。终端任务、本地文件处理和不需要网页的插件都能直接运行；安装并打开 Unzoo 浏览器后，macOS 与 Windows 都会自动识别并解锁带登录态的网页操作能力。

我的 API Key、对话和任务数据存在哪里？

全部留在本机。API Key 保存在受保护的本地文件（macOS/Linux 为 0600 权限）或系统凭据库中，个人版不经过任何云端中转服务器。

电脑睡眠或关机时定时任务会怎样？

关机时不会运行；睡眠期间错过的定时任务会在电脑唤醒后自动补跑。

可以自己写插件接入 Nissewyn 吗？

可以。任意包含 unzoo-plugin.json 的目录（Python / Node / Go / Rust 不限语言）都能接入控制页、设置表单和 MCP 工具，详见 插件开发指南。

BSL 1.1 开源协议有什么限制？

个人使用、公司内部生产使用、修改源码和自行编译都完全免费；仅限制未经商业授权将其打包成对外托管/竞争性 SaaS 服务。每个版本发布满 4 年后自动转为 Apache 2.0。
